# Sales CSV Analyzer

A beginner Python project that reads sales data from a CSV file, calculates revenue for each product, and saves a summary report.

## Data

`sales.csv` contains fictional restaurant sales for Pasta, Burger, Coffee, Salad, and Water.

## How to run

From the project folder, run:

```bash
python3 analyze_sales.py
```

Requires Python 3. No additional packages are needed.

## Results

The program displays each product's revenue and total units sold in the terminal. It saves total units sold and total, drinks, and food revenue to `sales_summary.txt`.

For the original sample data:
- Most sold product: Water (20 units)
- Total units sold: 63
- Total revenue: EUR 259.00
- Drinks revenue: EUR 85.00
- Food revenue: EUR 174.00

The generated report is excluded from Git because it can be recreated by running the script.
